# Personal Portfolio

A responsive GitHub Pages portfolio built with plain HTML, CSS, and JavaScript.

## Files

- `index.html` — portfolio content
- `style.css` — layout, colors, responsive design, animations
- `script.js` — mobile navigation and scroll reveal

## Before publishing

Replace these placeholders in `index.html`:

- `YOUR_EMAIL@example.com`
- `https://github.com/YOUR_GITHUB`
- `https://www.linkedin.com/in/YOUR_LINKEDIN`

You can also replace or add project links as projects become public.

## GitHub Pages

1. Create a repository named `YOUR_GITHUB.github.io`.
2. Upload `index.html`, `style.css`, and `script.js`.
3. Open the repository's **Settings → Pages**.
4. Select **Deploy from a branch**.
5. Select the `main` branch and `/ (root)`.
6. Save and wait for GitHub Pages to deploy.

Your site will be available at:

`https://YOUR_GITHUB.github.io`
